# 03 - Feature Matrix (Baseline vs Target)

เอกสารสรุปสถานะฟีเจอร์ทั้ง 12 หมวด ณ **Baseline Audit (Phase 1)** และแผนการปรับปรุง

| # | ฟีเจอร์ | สถานะเริ่มต้น (Audit) | ปัญหา/ช่องว่างที่พบ | แผนการแก้ไข |
|---|---|---|---|---|
| 1 | Account Registration & Auth | `PARTIALLY_IMPLEMENTED` | Register เชื่อม OpenMU แล้ว แต่ Login (`/api/account/login`) ใช้ mock fallback, ไม่ตรวจ password จริงบน OpenMU, ไม่มี session cookie และหน้า `/login` อ่านจาก `localStorage` | เพิ่ม `POST /api/accounts/authenticate` ใน OpenMU-Origins; สร้าง `web.web_sessions` + HttpOnly Cookie + CSRF + Rate Limit; เชื่อม LoginModal & `/login` กับ Backend จริง |
| 2 | Account Profile & Security (Change Password) | `IMPLEMENTED_BUT_BROKEN` | `PUT /api/account/changepassword` ยิง path ผิด, ไม่ตรวจรหัสผ่านเก่า, และ fallback คืน success ปลอม | เพิ่ม `/api/account/changepassword` ที่ตรวจ `oldPassword` ผ่าน `authenticate` + ตรวจบัญชี Offline + เรียก `PUT /api/accounts/{loginName}/password` |
| 3 | Character Management (List, Add Stats, PK Clear) | `IMPLEMENTED_BUT_BROKEN` | `characters/list` และ actions ทั้งหมดคืน mock JSON ใน `app.mjs` และ `dbApi.ts`, ไม่เช็ค ownership/online state | ขยาย Account DTO + เพิ่ม Character Self-Service Controller ใน OpenMU-Origins ใช้ `ILoginServer.TryReserveAccountAsync` แก้ไขอย่างปลอดภัยเมื่อตัวละคร Offline |
| 4 | Reset & Stat Reset | `IMPLEMENTED_BUT_BROKEN` | Frontend & `app.mjs` คืน success ปลอม ไม่ตรวจ Level 400 / ResetFeaturePlugIn / StatResetFeaturePlugIn | Implement `POST /api/accounts/{loginName}/characters/{name}/reset` และ `reset-stats` ใน OpenMU-Origins ตามกฎ `ResetFeaturePlugIn` & `StatResetFeaturePlugIn` |
| 5 | Character & Guild Rankings | `IMPLEMENTED_AND_VERIFIED` | อ่านจาก `ServerController` (`/api/rankings/characters`, `/api/rankings/guilds`) และ normalize class/stats แล้ว (ต้องตรวจความครบถ้วนร่วมกับ E2E) | รักษาการทำงานจริงและเพิ่ม integration tests |
| 6 | Online Player Statistics & Server Status | `IMPLEMENTED_AND_VERIFIED` | `ServerController.ServerStateAsync` รายงาน real realms & online player counts; `app.mjs` proxy ถูกต้อง | คงการทำงานจริงและปรับ `onlineExchange` config ให้สะท้อน Server Config |
| 7 | **P0-A: Online-Time Rewards** | `NOT_IMPLEMENTED` | `Account.OnlineTimeSeconds` มีอยู่แล้วใน OpenMU-Origins แต่ไม่ได้เปิดเผยผ่าน API และ `OpenMU-Web` ใช้ `localStorage` `availableHours` ปลอม | เปิดเผย `OnlineTimeSeconds` ใน `AccountController`; สร้าง checkpoint `redeemed_online_seconds` + `web.online_time_redemptions` + ACID transaction 1 hr = 5 Credits |
| 8 | Credit Wallet & Transaction History | `NOT_IMPLEMENTED` | ไม่มี DB schema เก็บ Credits/History; `UserHistoryPage` อ่านจาก `localStorage` | สร้างตาราง `web.wallet_accounts`, `web.wallet_ledger` และ API `/api/wallet/summary`, `/api/wallet/history` |
| 9 | **P0-B: Credit Exchange (Credits -> WCoinC)** | `IMPLEMENTED_BUT_BROKEN` | `dbApi.ts` เรียก `/api/rewards/online-exchange` แต่ไม่มี route นี้ใน `server/app.mjs` และ catch คืน success ปลอม | Implement `GET/POST /api/exchange/credits-to-wcoin` (และรองรับ `/api/rewards/online-exchange`) แบบ Outbox + `POST /api/accounts/{loginName}/cash-shop/grants` (Idempotent) + Compensation on reject |
| 10 | **P0-C: Credit Top-Up & Payment** | `IMPLEMENTED_BUT_BROKEN` | `/api/topup/donate` ไม่มีการยืนยันจ่ายเงิน, ไม่มี order state machine, ไม่มี idempotency/webhook, คืนสำเร็จปลอม | Implement `topup_orders` + Provider Adapter (PayPal Capture, PromptPay/Webhook HMAC, explicit Sandbox เฉพาะ Dev/Test) + Idempotent Credits & CashShop WCoinC Grant |
| 11 | Administrative Management | `IMPLEMENTED_BUT_BROKEN` | `AdminAuthContext` hardcode `admin/admin1234` + มีปุ่ม bypass `quickAdminLogin()`, `/api/admin/grant-balance` เชื่อ `body.adminUser`, `users/search` คืนข้อมูลปลอม | สร้างระบบ Admin Login จริงผ่าน `OpenMU-Origins` (`AdminUser`/API), Admin HttpOnly Session, User Search จริง, Grant Credits/WCoin, Ban/Unban/Disconnect |
| 12 | Security, Audit Logs & Abuse Prevention | `PARTIALLY_IMPLEMENTED` | มี Rate Limit เฉพาะ Register + Security Headers บน BFF แต่ขาด Session/CSRF, Wallet Concurrency Lock, Audit DB, และการปิด Mock Fallbacks | เพิ่ม Global Rate Limiters, Session + CSRF Middleware, Fail-closed Production Guard, ลบ Mock Fallbacks ทั้งหมดใน Frontend/BFF, เพิ่ม `web.web_audit_logs` |
